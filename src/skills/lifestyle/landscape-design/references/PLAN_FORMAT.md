# PLAN.md Format

The master design plan. Updated at the end of each session as more is learned. Structure adapts to what has actually been gathered — omit sections that have no meaningful content yet.

```markdown
# Landscape Design Plan — [Project Name or Address]

_Last updated: YYYY-MM-DD_
```

---

## Overview

A short paragraph summarising the design intent: what the space should feel like, how it will be used, and the overall approach.

## Space Summary

Key facts about the site: size, region, sun exposure, soil, existing features. Pulled from NOTES.md.

## Zones

A brief description of each identified zone and its role. Links to the detailed zone file.

- **[Zone Name]** — [one-line purpose] → `zones/zone-name.html`
- **[Zone Name]** — [one-line purpose] → `zones/zone-name.html`

## Phases

A brief description of each phase and what it covers. Links to the detailed phase file.

- **Phase 1: [Name]** — [one-line summary] → `phases/phase-1-name.html`
- **Phase 2: [Name]** — [one-line summary] → `phases/phase-2-name.html`

## Key Considerations

Constraints, risks, or decisions that cut across the whole design — e.g. drainage issues, budget trade-offs, phasing dependencies, HOA limits.

## Resources

Links or references worth keeping — inspiration sources, supplier suggestions, useful reading. Mirrors `RESOURCES.md`.

## Open Questions

Things still unresolved — to revisit in the next session.
