# shadcn/ui

A collection of copy-paste components built on Radix UI primitives and styled with Tailwind. Components live in your codebase — you own and modify them freely. Requires TailwindCSS.

---

## Setup

### React / Next.js

```bash
npx shadcn@latest init
```

Initialisation prompts: style (Default/New York), base colour, CSS variables. This creates `src/lib/utils.ts` with the `cn()` helper and writes Tailwind config extensions.

### SvelteKit — shadcn-svelte

```bash
npx shadcn-svelte@latest init
```

Creates `src/lib/utils.ts` with `cn()` and configures the component path at `src/lib/components/ui/`.

---

## Adding Components

```bash
# React / Next.js
npx shadcn@latest add button card dialog form input label

# SvelteKit
npx shadcn-svelte@latest add button card dialog form input label
```

Components are written to `src/components/ui/` (React) or `src/lib/components/ui/` (SvelteKit). They are yours — commit them, read them, and modify them.

## cn() Utility

`cn()` merges Tailwind classes and resolves conflicts using `tailwind-merge`. Always use it instead of `clsx` alone when combining with shadcn components.

```ts
// src/lib/utils.ts — generated by init
import { clsx, type ClassValue } from 'clsx';
import { twMerge } from 'tailwind-merge';

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

```tsx
// Correct conflict resolution — twMerge keeps 'p-6', removes 'p-4'
cn('p-4 bg-white', 'p-6')  // → 'bg-white p-6'

// Without twMerge — both classes apply, last wins unpredictably
clsx('p-4 bg-white', 'p-6') // → 'p-4 bg-white p-6'
```

## Usage

### React

```tsx
import { Button } from '@/components/ui/button';
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card';
import { cn } from '@/lib/utils';

<Card className={cn('w-full max-w-md', featured && 'border-primary')}>
  <CardHeader>
    <CardTitle>Title</CardTitle>
  </CardHeader>
  <CardContent>
    <Button variant="outline" size="sm" className="w-full">
      Action
    </Button>
  </CardContent>
</Card>
```

### SvelteKit

```svelte
<script lang="ts">
  import { Button } from '$lib/components/ui/button';
  import * as Card from '$lib/components/ui/card';
  import { cn } from '$lib/utils';

  let { featured = false } = $props();
</script>

<Card.Root class={cn('w-full max-w-md', featured && 'border-primary')}>
  <Card.Header>
    <Card.Title>Title</Card.Title>
  </Card.Header>
  <Card.Content>
    <Button variant="outline" size="sm" class="w-full">Action</Button>
  </Card.Content>
</Card.Root>
```

## Customising Components

Edit the generated file directly for permanent changes. Use `cn()` at the call site for one-off overrides.

```tsx
// One-off override — use cn() at call site
<Button className={cn('rounded-full', isLoading && 'opacity-50')}>

// Permanent change — edit the component file
// src/components/ui/button.tsx
const buttonVariants = cva('...base classes...', {
  variants: {
    variant: {
      default:   'bg-primary text-white hover:bg-primary/90',
      outline:   'border border-input hover:bg-accent',
      ghost:     'hover:bg-accent hover:text-accent-foreground',
      // Add custom variants here
      brand:     'bg-brand-500 text-white hover:bg-brand-600',
    },
  },
});
```

## Form Integration

shadcn/ui ships a `Form` component that wraps React Hook Form. See `references/frameworks/react.md` for the full RHF + Zod pattern.

```tsx
import { Form, FormControl, FormField, FormItem, FormLabel, FormMessage } from '@/components/ui/form';
import { Input } from '@/components/ui/input';
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';

const form = useForm({ resolver: zodResolver(schema) });

<Form {...form}>
  <form onSubmit={form.handleSubmit(onSubmit)}>
    <FormField control={form.control} name="email" render={({ field }) => (
      <FormItem>
        <FormLabel>Email</FormLabel>
        <FormControl>
          <Input type="email" {...field} />
        </FormControl>
        <FormMessage />
      </FormItem>
    )} />
  </form>
</Form>
```
