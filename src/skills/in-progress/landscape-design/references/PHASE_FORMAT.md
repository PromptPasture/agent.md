# PHASE-FORMAT.md

Each phase gets its own self-contained HTML file under `phases/`. Phases describe *when* and *in what order* work happens. A phase may span one weekend or one full season — scale to the project.

---

## What to Include

- **Header**
  - Phase number and name (e.g. Phase 1: Ground Preparation)
  - Suggested timing or season (e.g. Spring 2025, or "before planting season")
  - Estimated budget range for this phase (if known)
- **Goal**
  - One paragraph: what this phase achieves and why it comes in this order
- **Scope**
  - Which zones are touched in this phase
  - What work is included: clearing, soil prep, hard landscaping, planting, irrigation, finishing
  - What is explicitly deferred to a later phase
- **Key Tasks**
  - A prioritised list of the main tasks in this phase
  - Flag which tasks the homeowner can DIY vs. may need a professional
- **Dependencies**
  - What must be true before this phase starts (e.g. Phase 1 drainage complete, ground unfrozen)
  - What this phase unlocks for the next phase
- **Considerations**
  - Budget notes, seasonal timing constraints, supplier lead times
  - Common mistakes to avoid at this stage
- **Zone Reference**
  - Which zone files this phase relates to

---

## HTML Structure Guidelines

- Clean, readable layout — practical reference, not a mood board
- Phase number and name clearly visible at the top
- Task list should be scannable — use a simple checklist style
- Add a footer with last-updated date and link back to `../PLAN.md`
