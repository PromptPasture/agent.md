# 2026-06-10

- Approved design for splitting generic tracker-ticket writing out of
  `write-user-story` into an independent `write-ticket` skill.
- `write-ticket` will support bug, feature, task, and spike writing models;
  chores and documentation work map to task.
- The two skills remain independent. A request for both artifacts may trigger
  both, while conversion requires an explicit user request.
